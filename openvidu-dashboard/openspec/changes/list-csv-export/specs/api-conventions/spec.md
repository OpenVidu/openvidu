# Spec Delta

## ADDED Requirements

### Requirement: List CSV export endpoints

Edition: CE. A list with a CSV export SHALL answer `GET <list path>/export.csv` with the list's parameters except
`cursor` and `limit`, and the list's validation, ranked sort limits and errors. It answers `200`
`text/csv; charset=utf-8` as an attachment named `<list>-<from>-<to>.csv` (resolved instants, colons removed), with the
items of every page in the list's order.

#### Scenario: Ranked export of a range

- **GIVEN** 60 rooms created in the last 24 hours
- **WHEN** the client requests `GET /api/v1/rooms/export.csv?from=now-24h&to=now&sort=duration` with a valid token
- **THEN** the response is `200` with the attachment `rooms-<from>-<to>.csv`, a header row and 60 data rows in the
  order of the duration ranking at the request time

#### Scenario: Ranked sort beyond its limit

- **GIVEN** the default `DASHBOARD_LIST_TOTAL_MAX_RANGE` of 7 days
- **WHEN** the client requests `GET /api/v1/rooms/export.csv?sort=uniqueIdentities&from=now-30d&to=now`
- **THEN** the response is `400` JSON with code `SORT_RANGE_TOO_WIDE`, not a CSV body

#### Scenario: Exact ID

- **WHEN** the client requests `GET /api/v1/rooms/export.csv?q=RM_abc&from=now-1h&to=now` for a room created 3 days ago
- **THEN** the body holds the header row and the row of `RM_abc` only

#### Scenario: Nothing to export

- **GIVEN** no room created in the range
- **WHEN** the client requests the rooms export
- **THEN** the response is `200` with the header row only

#### Scenario: OpenAPI operation

- **WHEN** the client reads `GET /api/v1/rooms/export.csv` in the OpenAPI document
- **THEN** it has the `operationId` `exportRoomsCsv`, the rooms list parameters without `cursor` and `limit`, a `200`
  of `text/csv` declaring the `X-Export-Truncated` header, and its `400` and `401`

### Requirement: List CSV cells

Edition: CE. A list CSV SHALL be RFC 4180 with CRLF line ends and a header row of its resource's columns, named by
their JSON path (`participants.sessions`). Instants are ISO 8601 UTC, durations integer milliseconds, booleans `true`
or `false`, several values one cell joined by `;`, and an absent value an empty cell.

#### Scenario: Quoted value

- **GIVEN** a room named `Sales, Q4 "review"`
- **WHEN** the rooms export holds it
- **THEN** its `name` cell reads `"Sales, Q4 ""review"""`

#### Scenario: Several values

- **GIVEN** a participant session that published its camera and microphone
- **WHEN** the participants export holds it
- **THEN** its `publishedSources` cell reads `CAMERA;MICROPHONE`

#### Scenario: Absent value

- **GIVEN** an active participant session
- **WHEN** the participants export holds it
- **THEN** its `leftAt` and `durationMs` cells are empty

### Requirement: List CSV row cap

Edition: CE. A list CSV SHALL hold at most 10,000 data rows, the first ones in the list's order, and SHALL carry the
response header `X-Export-Truncated: true` when the list holds more items; a complete export has no such header.

#### Scenario: Cut export

- **GIVEN** 12,000 participant sessions joined in the range
- **WHEN** the client requests the participants export
- **THEN** the body holds 10,000 data rows, the most recent sessions by `joinedAt`, and the response carries
  `X-Export-Truncated: true`

#### Scenario: Whole export at the cap

- **GIVEN** exactly 10,000 participant sessions joined in the range
- **WHEN** the client requests the participants export
- **THEN** the body holds 10,000 data rows and the response has no `X-Export-Truncated` header

### Requirement: Index-backed list CSV exports

Edition: CE. Every list CSV export SHALL run its list's queries, on the same indexes, reading at most the cap plus
one item for the index-ordered sorts and the items of the range for the ranked ones. A 10,000-row export SHALL answer
within 2 s at the p95.

#### Scenario: Explain plans on the generated database

- **GIVEN** a database generated by the data generator at scenario M for 7 days
- **WHEN** the export of each list is explained with its default sort and with a ranked sort
- **THEN** each winning plan uses the index of its list query, none contains `COLLSCAN`, and the p95 of an export of
  10,000 rows is within 2 s

### Requirement: CSV formula neutralization

Edition: CE. Every CSV the API serves SHALL prefix with `'` a text cell that starts with `=`, `+`, `-`, `@`, a tab or
a carriage return, so that a spreadsheet opening the file shows the text instead of evaluating it. Numbers, instants
and enum values are written as they are.

#### Scenario: Room name as a formula

- **GIVEN** a room named `=HYPERLINK("http://example.com")`
- **WHEN** the rooms export holds it
- **THEN** its `name` cell reads `"'=HYPERLINK(""http://example.com"")"`

#### Scenario: Client value in an Analytics breakdown

- **GIVEN** participants whose browser was reported as `@cmd`
- **WHEN** the client requests `GET /api/v1/analytics/export.csv?kind=breakdowns&dimensions=browser`
- **THEN** that row's `key` cell reads `'@cmd`
