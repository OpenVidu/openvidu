## MODIFIED Requirements

### Requirement: Media statistics coverage

Edition: CE. The summary SHALL carry `mediaStats: "none"` when the rollup documents of its scope and snapped range,
in the collection the summary reads, have `mediaStats.missing` and none has `mediaStats.reported`; `"partial"` when
both marks appear; and no `mediaStats` property otherwise, including when no document carries a mark. It SHALL read
the marks with one aggregation backed by the `scope_bucket` index and never read `nodes`.

#### Scenario: No server reports media statistics

- **GIVEN** hourly documents in the range whose only marks are `mediaStats.missing: true`
- **WHEN** the summary is requested
- **THEN** the body has `mediaStats: "none"` and still carries `bytesUp` and `bytesDown`

#### Scenario: Some servers report media statistics

- **GIVEN** an hourly `global` document of the range with `mediaStats.missing: true` and another with
  `mediaStats.reported: true`
- **WHEN** the summary is requested with the `global` scope
- **THEN** the body has `mediaStats: "partial"`, as it does when a single document carries both marks

#### Scenario: Node scope

- **GIVEN** `node:mn-a` documents marked `missing` and `node:mn-b` documents marked `reported` in the range, and
  `scope=node:mn-b`
- **WHEN** the summary is requested
- **THEN** the body has no `mediaStats` property

#### Scenario: Restarts of one media node

- **GIVEN** `node:mn-a` documents of the range marked `reported` before a restart and `missing` after it
- **WHEN** the summary is requested with `scope=node:mn-a`
- **THEN** the body has `mediaStats: "partial"`

#### Scenario: Node seen outside the range

- **GIVEN** a document marked `missing` whose bucket is earlier than `from`, and documents marked `reported` in the
  range
- **WHEN** the summary is requested
- **THEN** the body has no `mediaStats` property

#### Scenario: Servers no longer in nodes

- **GIVEN** a 180-day range read from `analytics_daily`, whose buckets 120 to 100 days ago are marked `reported` and
  later ones `missing`, and `nodes` holding only the servers that do not report media statistics
- **WHEN** the summary is requested
- **THEN** the body has `mediaStats: "partial"`

#### Scenario: Rollups without marks

- **GIVEN** a range whose rollup documents were written before the marks existed
- **WHEN** the summary is requested
- **THEN** the body has no `mediaStats` property

#### Scenario: Coverage query plan

- **GIVEN** a database generated by the data generator at scenario M
- **WHEN** the coverage aggregation of a 30-day summary is explained
- **THEN** it uses `scope_bucket` and examines no more documents than the summary itself
